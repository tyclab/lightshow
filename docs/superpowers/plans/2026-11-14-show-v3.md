# Show v3: implementation plan

Spec: [`../specs/2026-11-14-show-v3-design.md`](../specs/2026-11-14-show-v3-design.md). Five pull
requests, each shippable by itself, each from main in its own worktree. Line numbers are from main
at `14930d49`; verify each before editing.

## Global constraints

- Read `AGENTS.md`, `docs/agents/header.md`, `implementation.md` and `validation.md` first.
- Failing test first, for every goal a pull request carries; a test that is rewritten because a
  ruling changed says so in the commit body, with the ruling.
- No route changes shape (spec, "Unchanged contracts"). New state keys are additive.
- The safety contract holds: every startup disarmed, flash limits, the photosensitivity
  acknowledgement, Blackout, output shutdown. A local preview never draws while armed.
- Public repository: no private address, no deployment identity, no source-application name, no
  home's own numbers. Comments at most 20 % of nonblank lines.
- Texts follow the draft the operator reviewed; behaviour follows the spec.
- README is updated in the same pull request as the control it describes; `header.md` gets the
  pull request's own bullets only.
- Gates before a pull request is ready: `npm run check`, `npm run test:e2e` with WebGL as
  `validation.md` describes (a motion test reads zero without it), no leftover process.
- Commit bodies say why, in prose; no attribution trailers.

## Review focus

1. Each goal's test exists, fails on main and passes on the branch; no goal is proven only by a
   screenshot or a mock.
2. A rewritten test still pins a ruling; none was weakened to pass (compare each with main).
3. Nothing is shown that does nothing, nothing lost its only access path: for every removed
   control, name where its function went.
4. Preview and output: no state in which a disarmed preview could be read as room light without
   its tag, and none in which a local preview draws while armed.
5. The Show block has no px, only the four width steps, and no script-computed size.
